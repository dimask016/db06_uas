✅ 1NF - First Normal Form (Atomic Values)Semua tabel sesuai struktur SQL
🧩 1NF: Tidak ada repeating groups. Data di bawah ini diambil langsung dari file logistik_inventory.sql (minimal 3-10 record per tabel).
✅ 1NF tercapai: Semua tabel atomic, tidak ada pengulangan grup. Qty_on_store ada di tabel Inventory, Good Receipt terpisah, Shipment memiliki driver_id & vehicle_id.
🧩 2NF - Second Normal FormMenghilangkan partial dependency pada composite key
🔍 2NF: Pada 1NF, jika ada composite primary key, atribut yang hanya bergantung pada sebagian key dipisah. Di database ini, TransferHeader dan TransferDetail sudah terpisah, Product independen.
✅ 2NF tercapai: Tidak ada partial dependency. Setiap atribut non-key bergantung penuh pada seluruh primary key.
